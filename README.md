# side-quests 🧪

*Curiosity in theory. Experiments in code.*

Not everything needs a roadmap. Some ideas just need a place to begin.

**side-quests** is my personal playground for exploring unfamiliar technologies, testing ideas, breaking things, and figuring out how they actually work — one experiment at a time.

From turning raw documents into searchable knowledge to building AI agents that collaborate, every project starts with a question and evolves through code.

### 🗺️ The Lab

| Experiment | What's happening |
|---|---|
| [`rag/`](https://github.com/prajwaljshetty/side-quests/tree/main/rag) | Teaching raw data to become useful knowledge through Retrieval-Augmented Generation. |
| [`agents/`](https://github.com/prajwaljshetty/side-quests/tree/main/agents) | Exploring AI agents, multi-agent orchestration, and systems that do more than generate text. |

### ⚗️ The Method

**Question → Experiment → Break → Understand → Build Again**

No pressure to get everything right on the first try. The goal is to understand the technology beneath the abstraction, not just make the code run.

### 🧠 The Philosophy

- **Explore beyond the syllabus.** Learn what curiosity leads to.
- **Understand before abstracting.** Know what's happening under the hood.
- **Build to learn.** Theory gives direction; experiments reveal the details.
- **Keep the failures.** Every broken attempt teaches something worth keeping.

---

*Main quests build the destination. Side quests build the developer.*
