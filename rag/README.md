# RAG

*Teaching machines to find context before they answer.*

An exploration of Retrieval-Augmented Generation (RAG) — connecting language models with external knowledge to build more grounded, context-aware applications.

Learning by building, experimenting, and figuring out what happens between a question and an answer.

### Exploring

- **Retrieval** — finding relevant information from a knowledge source.
- **Embeddings** — representing text as vectors for semantic search.
- **Augmented Generation** — giving LLMs useful context before they respond.
- **RAG Pipelines** — bringing retrieval and generation together.
