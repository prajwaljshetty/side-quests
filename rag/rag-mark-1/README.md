# RAG — Mark 1

*Every knowledge pipeline starts with raw data.*

My first experiment with Retrieval-Augmented Generation (RAG), focused on extracting text from PDF documents and exploring how raw documents can become usable knowledge for AI applications.

### The Experiment

**PDF → Text → Clean Data → Knowledge**

- Extract text from PDF documents.
- Inspect the extracted content and identify formatting noise.
- Understand document structure, including headings, page boundaries, and broken text.
- Explore how clean text becomes the foundation for chunking, embeddings, and retrieval.

### What I'm Learning

- PDF text extraction and document parsing
- Data quality and preprocessing for RAG
- Why clean input matters for downstream retrieval
- The building blocks of knowledge-grounded LLM applications

### Tech Stack

`Python` · `Jupyter Notebook` · `PDF Processing`
